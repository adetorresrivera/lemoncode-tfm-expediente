## Phase Goal

**As a** presenter, **I want to** have seeded data, a README and a responsive, accessible UI, **so that** the full demo runs in under 2 minutes on a clean machine.

This plan removes a rehearsal trap: a delete dialog that reopens with the previous attempt's error.

<objective>
Reset-on-open for the application delete dialog (D-16, 02 WR-03) plus regression tests for the round and document delete dialogs, flipped to `fixed`.

Purpose: DEMO-05 (rehearsals do not leave confusing state) and DEMO-04 (focus on the safe action).
Output: `resetDeleteError`, `onOpen` prop, three tests, disposition.
</objective>

- **Reset only an error, never an in-flight delete.** `resetDeleteError` clears the state only when it is `error`, so reopening cannot hide a delete that is still running.
