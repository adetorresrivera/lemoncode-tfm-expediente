## Assumptions and decisions (explicit, for the user to review)

- **Keep-alive is decided (D-26, user, plan review on 2026-11-06).** `OLLAMA_KEEP_ALIVE: "30m"` goes on the `ollama` service and the README documents the warm-up; no checkpoint remains in this plan.
- **Isolation through compose environment variables.** Cold mode exports `COMPOSE_PROJECT_NAME=expediente-cold`, `COMPOSE_FILE=compose.yml:scripts/compose.cold.yml` and `LLM_PROVIDER=mock`, so every existing helper targets the cold project with no call-site change; the override file resets the published ports, so the cold run never clashes with a running `expediente` stack on 8080 or 9001.
- **Compose version (README and smoke agree).** The `!reset` tag is the newest Compose feature the repository uses, so the README asks for Compose v2.24 or later and the cold smoke refuses to run on anything older with a clear message.
- **Image-size ceiling 450 MB (Claude's discretion, RESEARCH Open Question 7, resolved).** Current 397 MB; the ceiling catches an accidental dev-dependency or cache layer.
- **`--cold` is a separate flow.** It does not run the outage-recovery sections of the default smoke (those already run against the default project).
- **One EXIT trap per run.** The cold branch runs right after option parsing and ends with `exit 0` after `SMOKE OK`. The default flow registers `trap cleanup_smoke_records EXIT` (06-05) only after it creates its application, so a cold run never reaches that line. The cold teardown trap is the only EXIT trap, and neither trap replaces the other.
- **Demo offers folder.** `docs/demo/ofertas/` per D-09, confirmed by the user on 2026-11-06 as an exception to the CLAUDE.md file-name rule.
- **The seed runs detached inside the container** (`exec -d`) and is polled through files, because exec output can be dropped in this devcontainer.
- **Docs written after the code they describe.** The A7 «Pantallas» section of DESIGN.md and the fixture sentences land here, after 06-03 and 06-11 built them.
- **README does not duplicate docs.** It links `docs/` for detail and stays a runbook.
- **Edge coverage (spec-less fallback).** DEMO-02 was not classified by the edge probe (flagged assumption); its observable edges are the grep gates below and the human read-through in 06-17.
