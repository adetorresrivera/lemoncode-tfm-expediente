## Phase Goal

**As a** job seeker, **I want to** paste an offer and get a reviewable draft of the application form, **so that** I fill an application in seconds without losing anything I already typed.

This gap plan closes G-03-2 (major, UAT test 2): with gemma4:e2b, C, Python and Java came back as «language» (Idiomas) tags. The draft is only useful if the AI's tags land in the right group, so the user does not have to fix them by hand.
