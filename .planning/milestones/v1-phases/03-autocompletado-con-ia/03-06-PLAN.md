## Phase Goal

**As a** job seeker, **I want to** paste an offer and get a reviewable draft of the application form, **so that** I fill an application in seconds without losing anything I already typed.

This plan adds the tags slice: the AI's stack, «se valora» and language proposals join the user's tags without duplicates, and each proposed chip is visibly marked until the user keeps or removes it.

<objective>
Extend `mergeExtractionIntoForm` with the tag union and `aiTags`, add the optional `aiSuggested` mark to `TagChip`, thread the AI tag keys through `TagsSection` and `TagGroupInput`, keep them in the marks hook (pruned when a chip is removed), and count tags in the success line.

Purpose: tags are half of the draft in the demo (AI-06 merge, AI-07 mark at chip level per D-14/D-15).
Output: mapper and chip changes with tests, wiring and flow tests.
</objective>

## Assumptions (explicit, for the user to review)

- Merged tag order (Claude's discretion in CONTEXT): the existing tags first, then the new ones in model order; with `MAX_TAGS` reached, the user's tags are kept and the extra AI tags are dropped.
- A proposed tag whose key already exists in another group is not added (the user's spelling and group win), consistent with `normalizeTags` across groups.
- The chip icon is `size-3` (12 px), the lower bound D-14 allows, as UI-SPEC fixes it to stay on the 4 px grid.
