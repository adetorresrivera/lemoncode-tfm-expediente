## Phase Goal

**As a** sole user, **I want to** run `docker compose up` and open a themed Expediente shell at localhost:8080 backed by a healthy API, **so that** every later phase ships on a working end-to-end skeleton.

This plan expands the web layer of the skeleton: the tracer's bare `h1` becomes a routed, design-system-styled `/applications` screen with the course architecture in place.

Add the typed http-client (D-16) and the es-ES formatters (D-19) that Phase 2 consumes, all covered by Vitest + Testing Library.

</objective>
