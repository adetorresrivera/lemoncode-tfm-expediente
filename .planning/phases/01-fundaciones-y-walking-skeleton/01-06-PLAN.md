## Assumptions (explicit, for the user to review)

- The README is written in Spanish to match `docs/` and the defense audience; identifiers, commands and file names stay in English. It is intentionally minimal (D-22); Phase 6 (DEMO-02) completes it with seed and demo instructions.
- The first `--with-model` run downloads about 4.6 GB (`gemma4:e2b`) into the `ollama-data` volume and can take tens of minutes (RESEARCH A3); the executor runs it in the background and waits for completion. The app does not wait for this pull.
- If `ollama/ollama:0.40.3` cannot pull or serve `gemma4:e2b` (A1 fails), the executor stops, reports the error, and proposes the next Ollama tag published on or before 2026-10-14 that does; it never switches to a floating tag.
- Host-side checks (`curl` and a browser on the host) are human checks because the devcontainer drives the host Docker daemon and cannot reach published host ports (RESEARCH Pitfall 11).
