## Phase Goal

**As a** sole user, **I want to** run `docker compose up` and open a themed Expediente shell at localhost:8080 backed by a healthy API, **so that** every later phase ships on a working end-to-end skeleton.

This plan is the walking-skeleton tracer: the thinnest slice that crosses every layer the phase touches (npm workspace, contracts, API, Mongo/Silo/Ollama, built web, Docker image, compose). Later plans widen each layer without changing its architecture (see `SKELETON.md` in this directory).

<objective>
Prove the whole stack end to end on the riskiest seams first: npm 10 install with exact pins, contracts resolution without a build, a real `/api/health` against Mongo, Silo and Ollama, Hono static + SPA fallback, and the multi-stage image under `docker compose up`. Then harden the slice with the error contract, fail-fast env validation and `.env.example`, all proven by unit tests.

Purpose: every later phase ships on top of this skeleton; a dead end here must surface after one commit, not after ten.
Output: root workspace + lockfile, `@tfm/contracts` error/health schemas, `@tfm/api` health/error/static app, minimal `@tfm/web` entry, Dockerfile, compose.yml, `scripts/compose-smoke.sh`, `.env.example`, API and contracts tests.
</objective>
