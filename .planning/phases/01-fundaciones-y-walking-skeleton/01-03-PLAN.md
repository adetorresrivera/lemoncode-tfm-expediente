## Phase Goal

**As a** sole user, **I want to** run `docker compose up` and open a themed Expediente shell at localhost:8080 backed by a healthy API, **so that** every later phase ships on a working end-to-end skeleton.

This plan expands the contracts layer of the skeleton to every API model named in docs/ARCHITECTURE.md (the ROADMAP "contracts up front" note) and completes the provider-aware LLM client that feeds `/api/health`.

</objective>
