# Phase 01 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> Scope: the app shell and the `/applications` empty state only. Plan 01-04 lands `/` -> `/applications` (scene header + empty state, DS tokens, fonts). Plan 01-05 builds the shell (desktop sidebar, mobile header + Sheet, theme switch). No business screens, no forms, no filters, no data lists with content.
>
> Source of truth: `docs/DESIGN.md` and `docs/design/expediente.css` (locked, copied byte-for-byte to `apps/web/src/styles.css`). This contract only adds what those files leave open for the shell. Copy and layout decisions already fixed by plans 01-04 / 01-05 are reproduced here, not changed.

## Spacing Scale

Declared values (multiples of 4, Tailwind default 4 px unit):

| Token | Value | Usage in this phase |
|-------|-------|---------------------|
| xs | 4px (`gap-1`) | Gap between nav items; eyebrow -> h1 gap |
| sm | 8px (`gap-2`, `p-2`) | Icon-to-label gap in nav and toggle items; nav container padding |
| md | 16px (`p-4`, `px-4`) | Sidebar/header horizontal padding; nav item inline padding; mobile page gutter |
| lg | 24px (`p-6`, `gap-6`, `py-6`) | Empty-state card padding; scene header -> pod gap; mobile page vertical padding |
| xl | 32px (`px-8`, `py-8`) | Page gutter and vertical padding from `lg` (1024 px) up |
| 2xl | 48px | Not used in Phase 1 |
| 3xl | 64px (`lg:pl-64` = 256 px is the sidebar width, 4 x 64) | Page-level offset equals sidebar width |

Exceptions (all multiples of 4, all intentional):
- Sidebar width `w-64` = 256 px; content offset `lg:pl-64` must match it.
- Mobile header height `h-14` = 56 px; the sidebar brand block uses the same `h-14` so the wordmark baseline matches across breakpoints.
- Touch targets: the menu button is `size-11` (44 px); nav items in sidebar and Sheet are `h-11` (44 px). Theme toggle items are `h-9` (36 px, above the WCAG 2.2 AA minimum of 24 px).
- Content max width `max-w-5xl` (1024 px), centered with `mx-auto`.
- No 12 px spacing (`gap-3`, `px-3`) anywhere in the shell: it is not in the declared scale.

## Typography

Exactly 4 sizes and 2 weights (400 regular, 600 semibold) across the shell and empty state.

| Role | Size | Weight | Line Height | Where |
|------|------|--------|-------------|-------|
| Body | 16px (`text-base`) | 400 | 1.5 (`leading-normal`) | Empty-state text; brand wordmark «Expediente» (EB Garamond, weight 600); Sheet title (same style as the wordmark) |
| Label | 14px (`text-sm`) | 400 (active nav item and theme toggle selected item: 600) | 1.5 (`leading-normal`) | Nav item labels, theme toggle labels, Sheet description (sr-only) |
| Eyebrow | 11px (`text-[11px]`) | 600 | 1.5 (`leading-normal`) | Scene eyebrow «Expediente» (`uppercase tracking-[0.08em] text-muted-foreground`); «Próximamente» hint on disabled nav items |
| Display | 28px (`text-[28px]`) | 600 | 1.2 (`leading-[1.2]`) | Scene h1 «Mis candidaturas» (EB Garamond via the base layer `h1 { font-serif text-balance }`) |

Rules:
- Only `font-normal` (400) and `font-semibold` (600). The shadcn-generated primitives ship `font-medium` (500); plan 01-05 Task 1 post-processing replaces it with `font-semibold` or `font-normal` in `ui/*.tsx` (class-only edit, component APIs unchanged).
- Serif only on the wordmark and h1 (and later h2/h3 through the base layer). Everything operable (nav, toggle, buttons) is Source Sans 3.
- The scene h1 must wrap, never overflow: the wrapper has `min-w-0` and the h1 inherits `text-balance`.
- Not used in Phase 1 but already fixed by DESIGN.md for later phases: tag text 13 px, AI mark 11 px bold. They will be reconciled with this scale in the Phase 2 UI-SPEC.

## Color

Values come from `docs/design/expediente.css`. Components reference tokens only (CLAUDE.md: no hex, no `bg-blue-500`).

| Role | Light | Dark | Usage |
|------|-------|------|-------|
| Dominant (60%) | `--background` #f6f1e6 | #11151d | Page background (`bg-background`), main content area, text `text-foreground` (#1c2333 / #ece5d5) |
| Secondary (30%) | `--sidebar` #182b47, `--card` #fffdf8 | `--sidebar` #0c1018, `--card` #181e29 | Desktop sidebar, mobile header, Sheet content (`bg-sidebar text-sidebar-foreground`); empty-state card (`bg-card`) |
| Accent (10%) | `--sidebar-primary` #c9a961 (gold), `--ring` #1f3a5f (Oxford) | #d4b56a, #afc2dd | See reserved list below |
| Destructive | `--destructive` #9b2c2c | #b23a3a | Not used in Phase 1 |

Supporting tokens: `--border` (#dcd2bd) for the empty-state card; `--sidebar-border` (#2c4366 / #222a38) for sidebar/header/Sheet edges and the Separator; `--sidebar-accent` (#233a5c / #1a2130) for hover and the active nav item; `--muted-foreground` (#5a5e6a / #a39e92) for the eyebrow and the empty-state text.

Accent reserved for:
1. The 2 px left marker of the active nav item (`border-l-2 border-sidebar-primary`; inactive items keep `border-l-2 border-transparent` so nothing shifts).
2. The 1 px outline of the selected theme option (`border border-sidebar-primary`; unselected options use `border-transparent`).
3. Keyboard focus rings: `ring-sidebar-ring` (gold) on every focusable element inside the sidebar, mobile header and Sheet; `ring-ring` (Oxford, the DS default) on focusable elements over the page background.

Rules:
- Do not use the DS base-layer outline (`outline-ring/50`, Oxford at 50%) as the only focus indicator inside the navy sidebar/Sheet: its contrast against `--sidebar` is too low. Use an explicit `focus-visible:ring-2 focus-visible:ring-sidebar-ring` there.
- `brand-gold` is never used for text; no small text uses `brand-gold-ink` either in this phase.
- `primary` (Oxford) is not painted on any surface in Phase 1 (no primary button); the single-primary-action rule starts in Phase 2.
- Status colours (`status-*`) and `ai-missing-bg` are not used in Phase 1.
- Disabled nav items use `text-sidebar-foreground/70` (about 6:1 on `--sidebar`, AA). No lower opacity.
- Overlay colour is `bg-sidebar/70` (replaces the shadcn black overlay, per plan 01-05). Generated primitives must not keep `bg-black`, `text-white` or palette classes.

## Layout and Interaction Contract

### Breakpoints
- Base (360 px minimum, mobile-first): header + Sheet. No horizontal scroll at 360 px.
- `lg` (1024 px, Tailwind default): fixed sidebar replaces the header. At 1023 px the header must show; at 1024 px the sidebar must show. No intermediate tablet layout.

### Desktop shell (>= 1024 px)
- `aside`: `hidden lg:flex lg:fixed lg:inset-y-0 lg:w-64 flex-col bg-sidebar text-sidebar-foreground border-r border-sidebar-border`.
- Top: brand block `h-14 px-4`, wordmark «Expediente» (`font-serif text-base font-semibold`), vertically centered.
- Middle: `nav aria-label="Principal"` with `p-2`, items stacked with `gap-1`.
- Bottom: `Separator` (`bg-sidebar-border`), then `ThemeToggle` in a `p-4` block pinned with `mt-auto`.
- `main`: `lg:pl-64`; inner wrapper `mx-auto w-full max-w-5xl px-4 py-6 lg:px-8 lg:py-8`.

### Mobile shell (< 1024 px)
- `header`: `lg:hidden sticky top-0 flex h-14 items-center gap-2 px-4 bg-sidebar text-sidebar-foreground border-b border-sidebar-border`. Contains the menu button first, then the wordmark.
- Menu button: shadcn `Button` ghost, `size-11`, `aria-label="Abrir menú"`, `Menu` icon `size-5`; classes override hover to `hover:bg-sidebar-accent hover:text-sidebar-accent-foreground` and focus to `focus-visible:ring-sidebar-ring`.
- Sheet: `side="left"`, content `bg-sidebar text-sidebar-foreground border-sidebar-border`, default shadcn width (`w-3/4`, `sm:max-w-sm`). Contains `SheetTitle` «Expediente» (wordmark style), `SheetDescription` «Navegación principal» (`sr-only`), the same navigation component and `ThemeToggle` (after a Separator).
- The auto-generated close button keeps its position; its screen-reader text is changed from the English `Close` to «Cerrar» and it uses the sidebar focus ring.
- Open/close: controlled state. Following a nav link closes the Sheet. `Esc` and overlay click close it. Radix traps focus while open and returns focus to the menu button on close (do not re-implement).
- Motion: shadcn/tw-animate-css slide and fade only; add `motion-reduce:animate-none motion-reduce:transition-none` on the overlay and content. No theme-change transition (the switch is instant).

### Navigation items (shared by sidebar and Sheet)
- Item row: `flex h-11 items-center gap-2 rounded-md px-4 text-sm`, icon `size-5` + label.
- «Mis candidaturas» (`Briefcase`): TanStack `Link` to `/applications`. Active: `bg-sidebar-accent text-sidebar-accent-foreground font-semibold border-l-2 border-sidebar-primary`. Inactive hover: `hover:bg-sidebar-accent hover:text-sidebar-accent-foreground`.
- «Tablero» (`LayoutDashboard`) and «Documentos» (`FileText`): not links, not focusable, `aria-disabled="true"`, `cursor-not-allowed text-sidebar-foreground/70`, with the visible hint «Próximamente» aligned right in Eyebrow style (`ml-auto`). They have no hover state.
- Because the disabled items are not focusable, the keyboard tab order inside the nav is: «Mis candidaturas» -> theme radio group.

### Theme switch
- `ToggleGroup type="single"` with `aria-label="Tema"`, full width of its block, three items of equal width (`flex-1`), each `h-9`, icon `size-4` + label `text-sm` (Monitor/Sistema, Sun/Claro, Moon/Oscuro).
- Item colours inside the sidebar/Sheet: idle `text-sidebar-foreground`, hover `bg-sidebar-accent`, selected `bg-sidebar-accent text-sidebar-accent-foreground font-semibold border border-sidebar-primary`.
- Clicking the active item keeps it selected (guard in `onValueChange`). Arrow keys move between radios (Radix roving focus); only the selected item is in the tab order.
- At 360 px the three labels must fit in the 270 px Sheet without truncation; if they do not, hide the label below `sm` inside the Sheet only and keep `aria-label` on each item. Labels stay visible in the sidebar.

### Scene `/applications` (plan 01-04)
- Header stack: eyebrow «Expediente» (Eyebrow style), h1 «Mis candidaturas» (Display), `gap-1`; header -> pod `gap-6`.
- Empty state: `section` with `rounded-md border border-border bg-card p-6 text-base text-muted-foreground`. Single paragraph, no icon, no button (the «Añadir candidatura» button and the counter arrive with Phase 2).
- Focal point: the h1, then the empty-state card. No competing accent colour on the page body.
- `main` is the single `main` landmark; the scene h1 is the only h1 on the page (the wordmark in the header/Sheet is not a heading, except the `SheetTitle`, which Radix renders inside the dialog).

### Keyboard and accessibility
- Landmarks: `header` (mobile), `aside` (desktop), `nav` named «Principal», `main`. When the desktop sidebar and the Sheet both exist in the DOM, only one is visible; the Sheet content is mounted only while open.
- Every interactive element shows a visible focus ring (rules in Color). Icons are `aria-hidden`; labels are text.
- `prefers-color-scheme` drives the default; theme state is read from `localStorage["expediente-theme"]` with try/catch and a pre-hydration script, so no light frame is painted when Oscuro is stored.
- Skip link, `aria-live` regions and the full 360 px / contrast audit belong to Phase 6 (DEMO-03, DEMO-04); Phase 1 only guarantees the rules above.
