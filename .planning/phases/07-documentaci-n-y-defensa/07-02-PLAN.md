## Assumptions and decisions (explicit, for the user to review)

- **`.planning/` is read at the cut-off, not in the working tree.** Phase 7 adds PLAN and SUMMARY files under `.planning/phases/07-…`; reading through `git ls-tree` / `git show c11ab61:` keeps the counts frozen at Phase 6, as D-13 asks.
- **The test count is a figure too.** It is not in git or `.planning/`, so it is recomputed by running the suite (`--tests`, about 40 s). Product code does not change in this phase, so HEAD gives the cut-off count. Without `--tests` the script prints `SKIP tests (usa --tests)` and does not fail.
- **Token measurement is re-run, not copied.** RESEARCH §4 measured 1,004 / 884 / 922 input and 263 / 175 / 216 output tokens with Ollama, and 1,257 / 1,145 / 1,175 input (with schema) and 219 / 150 / 180 output with `o200k_base`. The executor re-runs both measurements. If Ollama is unreachable, it uses the RESEARCH values and labels them «medido el 7 nov 2026». Input with the JSON schema (about 1,192) is the conservative cloud figure. Input without the schema (about 860) is the lower bound, because the pricing guide does not say whether the strict schema is billed (RESEARCH A1). Reasoning tokens are left out («sin razonamiento», A2). The one retry of `callStructured` makes 2× the worst case.
- **`js-tiktoken@1.0.21` is a scratch-only tool.** The package audit returned OK. It is installed in a `mktemp` directory outside the repository, never in a `package.json`, so no legitimacy checkpoint is needed (T-07-SC). If the install fails, the RESEARCH `o200k_base` counts are used and labelled the same way.
- **Prices are re-fetched on the day.** The executor fetches `https://developers.openai.com/api/docs/pricing` (WebFetch, or `curl` if WebFetch is unavailable) and refreshes the access date. If both fail, it uses the RESEARCH rows (accessed 2026-11-07) and says so. Models in the table: the small ones (`mini` / `nano`) on that page. The RESEARCH list is the starting point; a model gone from the page is dropped.
- **Number format.** Spanish: decimal comma, thousands with a space from five digits (`10 000`), USD in the column headers. The checker parses that format.
- **No one-way doors.** Documentation and a dev-only script; all reversible.
- **Edge coverage (spec-less fallback).** PRES-03 came back `unclassified` from the edge probe and stays `unresolved`. Flagged assumption: its evidence is `check-figures.mjs` (every figure recomputed) plus the `--ia` contract. Figures about Phase 7 itself are deliberately out of scope (D-13).
