## Assumptions and decisions (explicit, for the user to review)

- **Smoke helper.** A new `http_upload PATH FILE_NAME TYPE SIZE_BYTES [PDF|TEXT]` mirrors `http_send` (argv only, result polled from `/tmp/smoke.out`), building the file bytes inside the container with `Buffer` and posting a `FormData` with `fetch`; the 6 MB body exercises the real `Content-Length` path of the 413.
- **Cleanup order.** The smoke deletes the application before the document (rule 4 would block the reverse), then checks the document is gone; a failure exits through `fail` as the existing sections do (the missing cleanup trap is the open Phase 2 finding WR-02, not addressed here).
- **Docs only describe what exists.** No new decisions are introduced in the docs; each change points to the plan that built it.
- **`npm run format:check`** is not part of the gate: STATE.md records that it flags the untracked `.gsd` sentinel; lint-staged already formats every committed file.
