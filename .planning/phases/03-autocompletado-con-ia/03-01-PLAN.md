## Phase Goal

**As a** job seeker, **I want to** paste an offer and get a reviewable draft of the application form, **so that** I fill an application in seconds without losing anything I already typed.

This plan is the phase tracer: the thinnest production-quality path from the «Pegar oferta» panel through `POST /api/offers/extract`, the extract service and the swappable `LlmClient` (the existing mock provider answers it end to end) back into the form. Later plans widen each layer without changing this architecture: real Ollama/OpenAI calls with timeout and retry (03-02), normalization, fixtures and logging (03-03), «IA» and «Complétalo tú» marks (03-04), tags (03-05), `offerText` (03-06), panel limits and cancel (03-07), phase gate and the manual model test (03-08).

<objective>
Wire one path end to end: contracts limits → `LlmClient.extractStructured` with an optional signal → `createExtractService` with the literal system prompt → `offersRoutes` mounted by `createApp` when `deps.llm` exists → `extractOffer` in the web pod → `mergeExtractionIntoForm` (fill-only-empty for the six text/enum fields) → `OfferPanel` with loading, success and error copy.

Purpose: a dead end in the dependency injection of the LLM, in the programmatic form write, or in the panel placement surfaces after one commit, not after eight plans.
Output: offers route and service with tests; `AppDeps.llm`; panel, hook, mapper and API call in the edit pod with tests.
</objective>
