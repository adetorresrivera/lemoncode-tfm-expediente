## Phase Goal

**As a** job seeker, **I want to** paste an offer and get a reviewable draft of the application form, **so that** I fill an application in seconds without losing anything I already typed.

This plan expands the tracer's API service: the draft the browser receives is clean whatever the model returns, nothing about the offer leaks into the logs, and the three fixture offers exist for the tests, the manual model check (plan 03-08) and the Phase 6 seed.

Add `normalizeExtraction` and the single `{ length, durationMs }` log line to the extract service, bound the request body, create the three fixtures with their expectations, and add the dev-only `try-extract` script that plan 03-08 runs against Ollama.

Purpose: AI-04 and the D-22..D-24 test assets; the user reviews a draft that never carries dirty or out-of-contract values.
Output: normalization and logging with tests, fixtures and scoring with tests, hardened route tests, `npm run try-extract`.
</objective>

## Assumptions (explicit, for the user to review)

- Pitfall 8 (RESEARCH Q6, user decision 2026-10-31): `offerExtractionSchema` already rejects labels over 40 characters and more than 20 tags, so with a real model an over-long label fails validation, is retried once and ends as 502 instead of being cut. The cut and the cap are still implemented in `normalizeExtraction` as the spec asks; they run on the fake-client tests. The SUMMARY documents the real-model behaviour; a lenient intermediate schema would change the JSON Schema sent to the model and needs the user's approval.
- `currency` is upper-cased in the normalizer (RESEARCH Q7, accepted).
- A draft that still fails `offerExtractionSchema` after normalization is a model failure: 502 `LLM_ERROR`, never 400.
- The log line is literally `console.info("offers.extract", { length, durationMs })`: the spec allows only length and duration; error codes already reach the log through `app.onError`'s fixed `err.message`.
- `try-extract` runs in-process by default (`createApp` with the real `createLlmClient(loadConfig())` and `app.request("/api/offers/extract")`, so no server or database is needed) and against a running API when `API_URL` is set. Both post to the same route.
- The `.txt` files are not copied by `tsc -p tsconfig.build.json`; the Phase 6 seed must read them from `src/offers/__fixtures__` or copy them (hand-over recorded in the SUMMARY).
- Spec-less edge probes lifted here: AI-04 adjacency, empty, encoding, ordering and concurrency; AI-02 precision (API part); AI-01 encoding (API part).
