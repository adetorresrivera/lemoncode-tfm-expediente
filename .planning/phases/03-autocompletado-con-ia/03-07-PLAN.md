## Phase Goal

**As a** job seeker, **I want to** paste an offer and get a reviewable draft of the application form, **so that** I fill an application in seconds without losing anything I already typed.

This plan finishes the «Pegar oferta» panel (AI-05): the user knows how much text the AI will accept, can stop a slow local model, and never loses control of the form while it runs.

<objective>
Add the length gate, counter and limit hints from the contracts constants (D-19), the read-only textarea and disabled trigger while analysing (D-20), and «Cancelar análisis» with the cancelled state and the single focus move (D-05, D-18).

Purpose: a CPU model can take tens of seconds; the panel must stay honest and interruptible during the demo.
Output: hook cancel and guards, panel states, flow tests.
</objective>

## Assumptions (explicit, for the user to review)

- The counter counts `draft.length` (what `maxLength` limits); the button gate counts `draft.trim().length` (what the API validates). Both are UTF-16 code units, the unit of `String.length` and of Zod's string checks.
- «Has llegado al límite …» replaces «Pega al menos …» when both could apply (they cannot: the limit implies at least 50 characters).
- The trigger is disabled while analysing so the textarea (read-only) and Cancel stay visible; the status region outside the collapsible keeps announcing either way.
- Spec-less edge probes lifted here: AI-05 idempotency and concurrency; AI-01 boundary and encoding (web part).
