## Phase Goal

**As a** presenter, **I want to** have seeded data, a README and a responsive, accessible UI, **so that** the full demo runs in under 2 minutes on a clean machine.

This plan polishes the first screen of the demo: a keyboard-honest shell (skip link, visible focus on the navy sidebar, 44 px targets) and a list that never flashes «no results» while a filter reloads.

## Assumptions and decisions (explicit, for the user to review)

- **Sheet close ring.** `SheetContent` gains an optional `closeButtonClassName` merged with `cn()`; the shell passes the `sidebar-ring` variant, the primitive default stays generic.
- **Counter during refetch.** Keeps the previous value when previous cards stay; becomes `null` (no counter) while the skeleton shows.
- **Edge coverage (spec-less fallback).** DEMO-03 and DEMO-04 were not classified by the edge probe; this plan covers their automatable part (class and behaviour assertions); 06-11 adds the 360 px guards and 06-17 the manual pass with fixes.
