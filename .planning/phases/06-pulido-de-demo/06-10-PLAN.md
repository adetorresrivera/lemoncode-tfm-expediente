## Assumptions and decisions (explicit, for the user to review)

- **Isolation through compose environment variables.** Cold mode exports `COMPOSE_PROJECT_NAME=expediente-cold`, `COMPOSE_FILE=compose.yml:scripts/compose.cold.yml` and `LLM_PROVIDER=mock`, so every existing helper targets the cold project with no call-site change; the override file resets the published ports, so the cold run never clashes with a running `expediente` stack on 8080 or 9001.
- **Image-size ceiling 450 MB (Claude's discretion, RESEARCH Q7).** Current 397 MB; the ceiling catches an accidental dev-dependency or cache layer.
- **`--cold` is a separate flow.** It does not run the outage-recovery sections of the default smoke (those already run against the default project).
- **The seed runs detached inside the container** (`exec -d`) and is polled through files, because exec output can be dropped in this devcontainer.
