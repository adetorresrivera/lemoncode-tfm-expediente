## Assumptions and decisions (explicit, for the user to review)

- **axe-core directly, not vitest-axe** (CONTEXT, Claude's Discretion): one devDependency with a maintained rule set; justification goes in the SUMMARY.
- **No human legitimacy checkpoint.** The audit verdict is OK (not `[ASSUMED]` or `[SUS]`), so the package-legitimacy gate does not require one; the version is pinned exactly.
- **Contrast from the real CSS.** The test reads `styles.css` itself, so a token change fails the build; the single config change lets Vitest return that file's raw text and nothing else.
- **Edge coverage (spec-less fallback).** DEMO-04 was not classified by the edge probe (flagged assumption); real focus rendering and contrast as painted by a browser stay in the 06-12 manual pass.
