## Phase Goal

**As a** job seeker, **I want to** create, find, review and move my applications through their states, **so that** I have one reliable record of every selection process.

This plan makes the list findable: server-side filters and sort on real Mongo, the filter state in the URL, and the free-text search with «Limpiar filtros».

<objective>
Implement every list filter and both sorts in the API exactly as D-03/D-04 define them (escaped regex, AND on stored keys, nulls last, no pagination per D-10), move the list state into URL search params with a serializer that keeps values as strings and degrades invalid values to "not applied" (D-13, APP-07), and give the user the search field, «Limpiar filtros» and the empty-by-filters state (D-14, APP-05/06).

Purpose: finding an application among dozens is the second half of the demo flow («see it filtered»).
Output: contracts query tightening; `applications.query.ts`, `query-input.ts` + real-Mongo tests; router serializer + lenient schema + tests; route/scene/pod wiring; filter panel, search field and empty-by-filters.
</objective>
